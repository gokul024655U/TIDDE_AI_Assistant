# 🤖 TIDDE - AI Personal Assistant

## 📌 Overview

TIDDE is a voice-enabled AI Personal Assistant developed using Python. It can understand voice commands, respond using text-to-speech, perform web searches, open applications, play music, and automate everyday tasks.

The project was built to improve my understanding of Artificial Intelligence, Speech Recognition, and Python Automation.

---

## 🚀 Features

- 🎤 Voice Command Recognition
- 🔊 Text-to-Speech Response
- 🌐 Web Search
- 🎵 Play Music
- 📖 Wikipedia Search
- 🤖 AI-based Conversation
- ⚡ Desktop Automation
- 🧠 Wake Word Detection
- 💬 Interactive User Experience

---

## 🛠 Technologies Used

- Python
- SpeechRecognition
- gTTS
- Pygame
- PyWhatKit
- Wikipedia API
- RapidFuzz
- VS Code
